# Field Edition 03 · 设计说明

目标：保留安静、短局的单人观鸟体验，同时让同屏双人的一次决定真正改变另一人的机会。此次不是给旧版本堆更多鸟卡，而是让移动、静候、观察与少量新增动作彼此产生联系。

## 新的选择如何发生

一个具体局面：苇青记录了浅汀的银腹浅鹬，留下惊扰；暖砂可以马上记录较普通的鸟，也可以花行动循声引来弯月燕鸥。后者的结果是确定的，却会把行动权交还苇青，因此要看苇青的位置、安静与目标。苇青选择静候，又会降低共享惊扰，可能让暖砂更容易拿到稀有鸟。

这使「恢复自己」与「改变公共场地」成为同一次行动的两种结果。玩家不需要攻击按钮，也能对对方的计划作出反应。

单人仍有独立的节奏：轻步适合多地点旅行，镜筒适合稀有鸟，手帖适合持续遇见新种。凝神是两次有限的补救机会；连章使观察顺序有价值；三枚印章提供不同程度的目标。换鸟则在行动紧张时提供新的机会成本。

## 保持轻量的取舍

- 没有加入额外货币、抽牌市场、隐藏手牌或复杂事件树。
- 公开双方分数、位置和资源，不用记忆力替代策略。
- 每个地点每轮只换一次，避免无限刷鸟；重复记录低分，避免靠同一位置重复操作取胜。
- 撤销保留，以便学习与共同讨论；它恢复整个共享局面，不能只回退一方的消耗。
- 同分平局；不给后手额外随机补偿。每轮更换先手，以平衡总先手次数。

## 证据与边界

25 项规则检查、浏览器完整单人 / 双人 / 平局对局，以及固定种子的开发搜索，证明已实现的流程和目标可运行。路线 731 单人轻步实际操作为 125 分；双人实际操作为 113–108。搜索不使用「循声换鸟」，仅证明基本动作也有达到三枚印章的路线，不证明最佳分数、三种行囊完全等强或适合所有玩家。

这是设计迭代和技术试玩，不是多人用户研究。「更有趣」仍需要人的体验反馈；本版把用户希望的互动落实成了可操作、可观察的共享机会与轮流决策。
