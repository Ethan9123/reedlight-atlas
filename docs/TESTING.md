# Field Edition 03 · 实际测试

日期：2026-11-18。Node.js 24.22.1；云端 Chromium。以下为开发验证与真实 UI 操作结果，不是官方评审或完整 AI 会话日志。

## 规则检查

`npm test`：25 / 25 通过。包含固定种子、正交移动与消耗、安静上限、观察门槛、惊扰与已观察鸟移除、重复记录、三项目标、六轮结束与结束后不可变性、坏存档、种子 0，以及：

- 三件行囊的能力与个人目标；每轮能力重置。
- 凝神次数、无行动消耗、无收益时禁用、只清除所在地惊扰。
- 连章奖励与中断条件；固定种子天气；三档印章；旧版单人迁移。
- 双人独立行动 / 安静 / 记录 / 分数，根状态与当前玩家镜像一致。
- 共享鸟踪 / 惊扰 / 换鸟；凝神不交棒；普通行动交棒。
- 双方耗尽行动才换轮、交替先手、六轮共 36 次付费行动与 6 次换轮。
- 双人序列化续局和损坏镜像拒绝。

## 手机布局

使用真实游戏置于 390×844 iframe 视口，不是实体手机或触摸仿真。滚动条后内容宽 375 CSS 像素，中英文均为 scrollWidth = clientWidth = 375，无横向溢出。新增双人状态栏重新排版；本轮测量中文游戏所有可见按钮高度均至少 44 CSS 像素。

实际执行观察、换鸟、撤销、凝神、重载续局、语言切换、打开 / 关闭规则、声音开关。iframe 顶部一次指针语言切换未改变状态，改用按钮键盘激活后成功；未将这次无效果操作记作成功点击。

## 离线

测试实际交付的内嵌 HTML，外部 script / stylesheet 引用均为 0，CSP 的 connect-src 为 none。在双人第二轮加载文件后，停止本地来源服务器并确认停止；随后通过真实 UI 完成后续五轮至 113–108 结算，双方图鉴仍正常。

这验证了加载后的运行不依赖来源服务器。未模拟操作系统断网，浏览器工具不支持 file://，因此未直接实测本地双击打开；采用经典内嵌脚本和样式以支持该方式。初次从私有网站下载需要联网及访问权限。无登录、广告、追踪、排行榜服务器或支付。

离线测试后只调整了手机触控尺寸 / 状态栏 CSS、单人版本标记和重开时清除旧提示；未改变规则和资源加载方式，最终内嵌文件再经过静态无外部引用检查。

## 搜索、格式与可复现性

最终规则下，宽度 160 的有限搜索得到：路线 731 三种行囊 125 / 120 / 126 分，路线 137 为 123 / 121 / 122 分。均达到三枚印章及个人挑战。`balance-search.json` 保存动作序列；搜索未包含换鸟，只验证目标可达，不证明最优或完整平衡。

`duel-ui-path.json` 是开发工具产生、用于 UI 回归的游戏动作样例，不是人类试玩数据或 AI 会话记录。实际浏览器双人对局与样例终局相同。

`npm run validate` 两次运行 main.ts，比较所有 11 个输出文件及 stdout；核验截图、文件数 / 大小 / 路径、无外部运行引用及官方适配器哈希。数据写入 `validation.json`。源码 ZIP 两次构建另行比较 SHA-256。均为本地验证，未运行官方完整评审。
